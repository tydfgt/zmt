## 快速命令

```bash
# 激活虚拟环境
source venv/bin/activate

# 检查配置
python -m publisher.cli check

# 试运行
python -m publisher.cli publish article.md --all --dry-run

# 正式发布
python -m publisher.cli publish article.md --all --optimize
```

详细文档请见仓库根目录的 [README.md](../README.md)。
